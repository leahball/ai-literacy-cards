Setting up on GitHub Pages

1
Create a new public repo — e.g. ai-literacy-cards
2
Upload this file as index.html and create a blank notes.json file containing {}
3
Go to Settings → Pages → Deploy from branch → main → / (root). Save.
4
Your app lives at https://[yourusername].github.io/ai-literacy-cards
5
To save notes: type a note on any card, click "Save & export", copy the JSON, paste it into notes.json in your repo and commit. Notes load from the file on next visit.
6
To add new cards: ask Claude to update the DECKS object in this file with new cards, re-upload.
